# Licences

One plain-text file per bundled third-party asset, named after the asset, e.g.
`fajr_makkah.txt`, containing:

```
Source:      <url>
Author:      <reciter / studio>
Licence:     <SPDX id>
Version:     <date or version fetched>
Attribution: <exact credit text shown in-app>
```

The app shows every file here in **Settings → Credits**.
