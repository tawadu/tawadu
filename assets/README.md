# Assets

Everything user-visible that is not code lives here, each with its own licence.

| Folder | Contents | Licence rule |
|---|---|---|
| `voices/` | Athan recordings, grouped into packs | one licence per file; see [../docs/attribution.md](../docs/attribution.md) |
| `athkar/` | Athkar corpus (JSON) and narration audio | MIT / CC BY as noted per source |
| `sounds/` | Notification and iqamah chimes | must be CC0/owned |
| `fonts/` | IBM Plex Sans, IBM Plex Sans Arabic, Amiri | SIL OFL 1.1 |
| `licenses/` | Per-file licence/attribution text | — |

**Never commit an asset without a licence entry.** Packs are described in
[../docs/voice-pack-format.md](../docs/voice-pack-format.md).
